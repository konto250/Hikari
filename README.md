# 光採り

光採りは、目のハイライトを白の基準にして、写真やアバターのスクリーンショットの色を補正する Windows 用のデスクトップアプリです。左右の目のハイライト候補から最も明るい1画素を選び、その色で画像全体のRGBを除算します。補正前後をプレビューで見比べ、使う色の明るさを調整してから、元画像への上書きまたは別名のPNGとして保存できます。

## ビルド方法

光採りは C# / WPF 製で、対象フレームワークは `net10.0-windows` です。Windows に .NET 10 SDK をインストールし、`Hikari.csproj` があるフォルダーで PowerShell を開いて次のコマンドを実行します。

```powershell
dotnet build .\Hikari.csproj -c Release
```

ビルドに成功すると `bin\Release\net10.0-windows\Hikari.exe` が生成されます。

## 起動方法

同じ PowerShell から次のコマンドで起動し、編集したい画像をウィンドウにドロップします。エクスプローラーで `Hikari.exe` をダブルクリックしても起動できます。

```powershell
.\bin\Release\net10.0-windows\Hikari.exe
```

開発中は `dotnet run --project .\Hikari.csproj -c Release` でビルドと起動をまとめて実行できます。別の Windows PC でビルド済みのアプリを使う場合は、出力フォルダーごとコピーし、実行先に .NET 10 デスクトップランタイムをインストールします。

## 使い方

1. 画像をドロップするか、「画像を開く…」から選びます。左右のハイライト候補を検出すると、除算結果が表示されます。
2. 拡大表示で採色位置を確認します。「元画像」に切り替えると画像全体でも位置を確認できます。別の箇所を採色する場合は「目の範囲を指定…」を押し、元画像上で反射光を小さく囲んでください。指定範囲で最も明るい画素が選ばれます。クリックすると、その1画素を使います。
3. 「明るく」「暗く」は**除算に使う色**を5%刻みで白または黒に近づけます。除算色を明るくすると結果の画像は暗くなります。「検出色に戻す」で調整量が0%に戻ります。
4. 「元画像に上書き保存」を押すと、除算結果を開いたファイルと同じ名前・形式で保存します。PNG、JPEG、BMP、TIFF に対応し、JPEG は再圧縮されます。画像を開き直すまでは、上書き後の明暗調整も最初に読み込んだ画素を基準に計算します。別ファイルに保存するには「PNG に名前を付けて保存…」を使います。

プレビューの画像にマウスを置くと手形になり、左ドラッグで画像全体を移動できます。「目の範囲を指定…」では十字カーソルに切り替わり、ドラッグで採色範囲を囲めます。ホイールを上に回すとカーソル位置を中心に拡大し、下に回すと縮小します。「全体表示」で倍率と位置を戻せます。元画像と除算結果を切り替えても表示位置は共通です。

## 採色と合成

自動検出は、周囲より明るい小さな点を複数の大きさで探し、位置関係・反射色が似た左右の候補を選びます。その内部を元解像度で調べ、sRGB を線形化した相対輝度（0.2126 R + 0.7152 G + 0.0722 B）が最も高い実在の1画素を採用します。片目が隠れている画像や装飾の反射を拾う画像では、手動の範囲指定を使用できます。

読み込んだ画素は各成分32ビットの浮動小数点で保持します。16ビットのRGB・RGBA・グレー画像も元の精度から読み込みます。除算には画像に記録されたRGB値を使い、白を1とすると各成分の結果は `元の成分 ÷ 除算色の成分` です。除算色の成分が0なら、元の成分が0のときは0、それ以外は1として扱います。透明度は元の値を引き継ぎます。

明暗調整で生じる端数や、除算で白を超えた値は計算中も保持します。画面の色見本・HEX表示・プレビューは8ビットの近似表示です。保存には内部の浮動小数点値を使い、整数画像に書き出す時点で範囲を制限して丸めます。8ビットのRGB PNGは8ビットRGBに、16ビットのRGB・RGBA・グレーPNGはそれぞれ元のビット深度とチャンネル構成に戻ります。元から浮動小数点のTIFFを開いた場合は、別名の16ビットPNGに書き出せます。
